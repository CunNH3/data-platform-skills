# 数据平台使用

## 说明书更新

- 管理员提供正式在线说明书目录后，执行前先读取目录及本次所需文档；当前按下表读取本包自带的本地正文，无需访问源码仓库或安装其他 Skill。
- 只读取本次任务需要的文档。接口与规范集中在 references，本地 Skill 不会自行拉取远程版本。

## 共同约定

- 默认生产环境，只有用户明确指定才切换；一次操作中的数据、开发机和 Job 使用已确认的环境，不自动跨环境切换。
- 复用用户已提供的配置和本机认证，只合并询问缺失项；参数确认和资源检查按对应说明执行，不因 Skill 被调用就创建资源。
- 数据读取使用 DataClient；处理任务的数据结果统一为 TD，上传核验后必须登记到数据平台，返回结果数据 ID 和存储地址。
